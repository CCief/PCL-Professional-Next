WHAT'S NEW

相比 PCL Pro，多了这些

这一层增强由本项目独立开发，与上游功能无关；源码来自对已发布产物的反编译重建，仅供逆向学习与可复现构建研究。

⚡

快捷下载

搜索到模组后跳过详情页直接开始下载，不再逐个点进卡片。

🧩

自动下载前置

自动识别并安装依赖，已安装的自动跳过；修复了前置文件被标成父项目中文名的问题。

🎯

版本 / 加载器匹配

按已安装的 Minecraft 版本与加载器自动选择对应文件，避免装错版本。

💾

开关状态记忆

快捷下载与自动前置的开关状态自动保存，重启后不用重新设置。

📅

日历版本正确分组

26.x 这类日历版本不再被误归进「远古版本」，筛选条里的复选框也会跟着卡片动画走。

🛠️

稳定性修复

修复提示框误带输入框、CLR invalid program 崩溃与下载页布局错位等问题。

RELEASE CHANNELS

三条发布通道，各管一段

通道由版本标签后缀唯一决定，不靠人工标记。想尝鲜就走 Alpha，想帮忙测试就走 Beta，求稳就等 Release。

ALPHA

实验通道

随时构建，允许不稳定。用于新功能研发和实验，功能可能随时被修改或删除，不受稳定版开发路线限制。

vX.Y.Z-alpha[.N]
GitHub 标记：Pre-release
BETA

测试通道

稳定版的测试版本。经过初步筛选的 Alpha 功能可能被合并进来，并进行进一步优化和稳定性测试；进入即功能冻结。

vX.Y.Z-beta[.N]
GitHub 标记：Pre-release
RELEASE

正式通道

正式发布版本。由 Beta 版本经过较长时间、广泛的公众测试和问题修复后发布，是目前最稳定的版本。

vX.Y.Z
GitHub 标记：Latest

晋升顺序：Alpha → Beta → Release；同一个 X.Y.Z 只晋升一次。完整规则见仓库 RELEASE_CHANNELS.md ↗。当前对外版本序列自 v0.1.0-alpha 起算，此前的 v1.0.x 仅为内部迭代编号。
